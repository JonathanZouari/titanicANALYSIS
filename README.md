# Titanic Analysis

פרויקט ניתוח נתונים של נוסעי הספינה טיטאניק, על בסיס קובץ `Titanic.csv`.

## קובץ הנתונים

| מאפיין | ערך |
|--------|-----|
| **שם הקובץ** | `Titanic.csv` |
| **מספר שורות** | 891 נוסעים |
| **מספר עמודות** | 12 |

## מבנה העמודות

| עמודה | תיאור |
|-------|--------|
| `PassengerId` | מזהה ייחודי לכל נוסע |
| `Survived` | האם שרד (0 = לא, 1 = כן) |
| `Pclass` | מחלקת כרטיס (1, 2 או 3) |
| `Name` | שם מלא של הנוסע |
| `Sex` | מין (male / female) |
| `Age` | גיל |
| `SibSp` | מספר אחים/בני/בנות זוג על הספינה |
| `Parch` | מספר הורים/ילדים על הספינה |
| `Ticket` | מספר כרטיס |
| `Fare` | מחיר הכרטיס |
| `Cabin` | מספר/אות תא |
| `Embarked` | נמל עלייה (C = Cherbourg, Q = Queenstown, S = Southampton) |

## תובנות עיקריות

1. **מין** — שיעור ההישרדות בקרב נשים גבוה משמעותית מבקרב גברים.
2. **מחלקה** — נוסעי מחלקה ראשונה שרדו בשיעור גבוה יותר.
3. **נתונים חסרים** — עמודת `Cabin` דלילה מאוד; יש לטפל ב-`Age` לפני מודלים.
4. **אי-איזון** — רוב הנוסעים במחלקה 3; שיעור ההישרדות הכללי נמוך (~38%).
