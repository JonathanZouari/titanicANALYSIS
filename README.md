## מסקנות

1. **מין ומחלקה** מסבירים את רוב הפער בהישרדות. נשים במחלקה 1–2 כמעט תמיד שרדו; גברים במחלקה 3 כמעט תמיד לא.
2. **ילדים** ונוסעים במשפחה קטנה-בינונית שרדו יותר מנוסעים לבד.
3. **מחיר כרטיס ומספר תא** הם בעיקר פרוקסי למעמד, לא גורם עצמאי.
4. לנתונים חסרים: להשלים `Age` לפי מין/מחלקה/תואר, `Embarked` במצב (S), ולהמיר `Cabin` לדגל בינארי.

אם תרצה שלב הבא: מודל חיזוי פשוט (לוגיסטי / עץ) עם פיצול train/test ומדדי דיוק.
