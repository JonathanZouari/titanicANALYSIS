# Titanic — ניתוח הישרדות

| --- | --- |
| PassengerId | מזהה |
| Survived | שרד (1) / לא (0) |

| Name, Sex, Age | דמוגרפיה |
| SibSp, Parch | בני משפחה על הסיפון |
