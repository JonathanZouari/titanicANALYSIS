# Titanic Analysis

ניתוח נתונים של נוסעי הטיטאניק — בדיקת הגורמים שהשפיעו על סיכויי ההישרדות.

## נתונים

`Titanic.csv` — 891 נוסעים, 12 עמודות:

| עמודה | תיאור |
|-------|-------|
| PassengerId | מזהה נוסע |
| Survived | 0 = נספה, 1 = שרד |
| Pclass | מחלקת כרטיס (1/2/3) |
| Name | שם מלא |
| Sex | מין |
| Age | גיל (חסרים ערכים) |
| SibSp | אחים/בני זוג על הסיפון |
| Parch | הורים/ילדים על הסיפון |
| Ticket | מספר כרטיס |
| Fare | מחיר הכרטיס |
| Cabin | תא (חסרים ערכים רבים) |
| Embarked | נמל עלייה (C/Q/S) |

## שאלות מחקר

1. האם מין הנוסע השפיע על סיכויי ההישרדות?
2. מה הקשר בין מחלקת הכרטיס להישרדות?
3. כיצד הגיל משפיע על ההישרדות?
4. האם נסיעה עם משפחה שיפרה את הסיכויים?

## ניתוח קצר (פחות מדקה)

מתוך 891 נוסעים שרדו **38%** (342). שני הגורמים החזקים ביותר הם **מין** ו**מחלקה**.

- **מין:** נשים שרדו ב־74%, גברים ב־19%. נשים במחלקה 1–2 שרדו כמעט כולן (97% ו־92%); במחלקה 3 רק מחצית. גברים במחלקה 1 שרדו ב־37%, ובמחלקות 2–3 כ־14–16% בלבד.
- **מחלקה:** 63% במחלקה 1, 47% במחלקה 2, 24% במחלקה 3.
- **גיל:** ילדים עד 12 שרדו ב־58%; מעל זה השיעורים יורדים בהדרגה (כ־34–43%). ל־177 נוסעים אין גיל רשום.
- **משפחה:** נוסעים עם משפחה קטנה (1–3 קרובים) שרדו ב־58%; לבד — 30%; משפחה גדולה (4+) — רק 16%.

**מסקנה:** מדיניות "נשים וילדים תחילה" ומעמד כלכלי מסבירים את רוב הפער. נסיעה עם משפחה קטנה עזרה; משפחה גדולה פגעה בסיכויים.
